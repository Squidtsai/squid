# squid — iPhone 防護健檢

一個給 iPhone 用的網頁工具（PWA），幫你把 iOS 內建的安全功能一項項開起來，並檢查可疑簡訊與密碼外洩。

> **為什麼不是 App？** iOS 的沙盒機制不允許任何第三方 App 掃描系統或其他 App，
> 所以號稱能「掃毒」的 iPhone App 實際上做不到。真正有效的防護，是把 Apple 內建、
> 但大多預設沒開的功能打開。這個工具就是帶你完成這件事。

## 功能

| 分頁 | 內容 |
| --- | --- |
| 🛡️ 健檢 | 38 項 iPhone 安全設定（失竊裝置保護、雙重認證、進階資料保護、鎖定模式、描述檔檢查、SIM PIN…），附上設定路徑與原因，依重要性計算防護分數，進度存在手機上 |
| 🔗 連結檢查 | 貼上簡訊或網址，在本機分析：冒用品牌網域、相似字元、Punycode、IP 網址、縮網址、高風險網域，以及台灣常見詐騙話術（ETC 欠費、包裹、假檢警、解除分期、投資群組） |
| 🔑 密碼 | 強度評估，並透過 Have I Been Pwned 的 k-匿名 API 查詢是否外洩（只送出 SHA-1 雜湊值的前 5 碼） |
| 🚨 應變 | 入侵徵兆自我檢查與 10 步驟應變流程，附 165 / 110 一鍵撥打 |

## 隱私設計

- 不會上傳任何內容；唯一的對外連線是 `api.pwnedpasswords.com`（只送出雜湊值前 5 碼）
- 用 CSP 限制只能連到該網域，且不使用第三方腳本、字型或追蹤
- 勾選進度只存在瀏覽器的 localStorage

## 使用方式

1. 部署到任何 HTTPS 靜態主機（例如 GitHub Pages：Settings → Pages → 選擇分支）
2. 用 iPhone 的 Safari 打開 → 分享 → **加入主畫面**，就能像 App 一樣全螢幕、離線使用

本機開發：

```sh
npm start     # http://localhost:8080
npm test      # 執行連結分析與密碼檢查的單元測試
```

## 限制

- 連結分析是啟發式規則，「沒有發現問題」不代表一定安全
- 設定路徑以 iOS 18 以上為準，Apple 改版後可能需要更新 `js/checklist-data.js`
